آزمایش تشخیصی API

این صفحه فقط درخواست‌های آزمایشی می‌فرستد؛ هیچ فیلد کلید API ندارد و فقط در T3 و T4 مقدار ساختگی Bearer test می‌فرستد.

T2 یک POST بدون احراز هویت می‌فرستد تا رفتار پاسخِ سادهٔ مرورگر بررسی شود. بدنه حداکثر یک توکن خروجی می‌خواهد؛ اگر سرویس‌دهنده درخواست ناشناس را بپذیرد، ممکن است مصرف اندکی ایجاد شود.

گزارش

گزارش شامل کلید نیست. پیش از اشتراک‌گذاری، فقط مطمئن شو اطلاعات دیگری که نمی‌خواهی منتشر شود در گزارش نیست.

یادآوری: `Failed to fetch` به‌تنهایی علت را مشخص نمی‌کند. تفکیک قطعی ممکن است به لاگ سرور یا ابزار شبکهٔ مرورگر نیاز داشته باشد.
